# Personal workflow

Match the process to the size of the request. Handle quick, self-contained work
directly without requiring an issue tracker or formal planning workflow.

Follow repository-specific instructions and use the repository's established
tools when they exist. Use Beads when the user requests it, the repository
requires it, or a Beads-focused custom agent is active; otherwise, do not
assume Beads is available or required.

Keep communication concise and practical. Ask before making consequential or
ambiguous product and architecture decisions, but use reasonable defaults for
small, reversible choices.
